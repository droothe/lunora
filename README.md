# Lunora Atelier

Lunora Atelier, kuaför ve güzellik salonu hizmetlerini tanıtan ve randevu akışını gösteren bir web sitesi demosudur. Ziyaretçiler hizmetleri, uzmanları ve örnek galeriyi inceleyip hizmet, uzman, tarih ve saat seçerek randevu talebi oluşturabilir. Özel/mahrem hizmet tercihi de randevu adımlarında belirtilebilir.

`/admin` demo yönetim ekranında randevu durumları, takvim, hizmet/fiyat bilgileri ve örnek müşteri kayıtları görüntülenip düzenlenebilir. Bu proje bir arayüz demosudur; salon, kişi ve iletişim bilgileri örnek, etkileşimli veriler ise uygulama içi durumla yönetilir.

## Geliştirme

Gereksinimler: [Bun](https://bun.sh/)

```sh
bun install
bun run dev
```

Üretim derlemesi için `bun run build`, testler için `bun run test` komutlarını kullanın.
